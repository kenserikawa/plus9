# Plus 9

Vanilla HTML/CSS/JS number puzzle: drag or tap tiles into the centre until they add up to the target exactly. No build step for local play, no dependencies, no package.json. Open `index.html` directly (file:// works). The page makes **no external requests** (fonts are bundled); web portals require this, so keep it that way. There is **no server**: all progress lives in `localStorage` (see *Saving*).

## Screens and modes

- **Home** (`#home`): Journey card (world and next level, total stars), Daily / Classic / 60 seconds cards, today's missions, and the Customize card (Nine as dressed, current theme) that opens the `#style` sheet: Nine's wardrobe and the themes. A first-time player skips it and lands in Journey level 1 (`plus9.onboarded` is set when they win it).
- **Journey map** (`#map`): a winding route of levels (`renderMap`); finished levels show their stars, the next one is gold, later ones locked. Tapping a level starts it at once (no intro screen); "Next level" on the result does the same. A level's goal and star thresholds show as a coach tip when it starts (`coach.goal`), unless that level has a lesson tip. The route fades out at its top and bottom edges. `drawRoad()` draws an SVG under the nodes with an S-curve from each node's centre to the next: stretches after a level with a star are an ink-cased rainbow that slides along (SMIL `animateTransform`, off with reduced motion); the rest are dotted. It measures the nodes, so it reruns on resize. - **Game** (`#game`): bar (home, title, pause, sound), HUD, coach tip, board, actions. The HUD's 2nd and 3rd pills change with the mode (`renderHud`): Level/Best (Classic, 60 s), Sums/Par (Daily), Stars/Sums (Journey).
- Starting any game calls `platform.commercialBreak()` first; `goHome()` abandons the current game (Classic/60 s records are kept, the daily keeps its own saved progress).

## Rules (as implemented)

- **Tiles**: 8 tiles, values 1…`target − 1`, weighted towards small numbers: P(v) ∝ exp(−v / λ), λ per level from `TILE_LAMBDA`. Playing a tile adds it to the well and the tile becomes the **Next** value. Four random colors.
- **Scoring**: a completed sum scores `tiles used × level`, **×2 when every tile has the same color** (a combo, at least 2 tiles; wild tiles match any color), and ×2 more for each ×2 tile in it.
- **Special tiles** (`drawTile` rolls them; every draw consumes the roll so seeded sequences don't shift): **★ wild** (`WILD_CHANCE` 3 %) is worth exactly what the sum still needs (`tileValue`), so it always finishes it; **×2** (`DOUBLE_CHANCE` 6 %) doubles its sum's points; **rainbow** (`RAINBOW_CHANCE` 4 %) keeps its number but matches any color, so it never breaks a combo (`anyColor`, `keepsCombo`). Its digit is drawn twice: the ink-outlined number, and an `::after` copy (from `data-n`) filled with a rainbow gradient clipped to the glyph, about one glyph wide and sliding slowly (the one idle animation on a tile, stopped by reduced motion). A rainbow part fills the ring with cycling colors. **Frozen** tiles (`ice`, journey only) can't be played (`canPlay`) and thaw by one per completed sum (`ICE_SUMS` = 2); shuffles leave them in place.
- **Classic streak** (`streakOn()`, only `mode === 'classic'`): a completed sum goes into a **pot** instead of the score, the k-th sum in a row worth k × its points (`streakMultiplier`, capped at `STREAK_MAX` = 5). **Cash in** (`cashIn`, `#cash`, key `C`) moves the pot to the score and restarts the streak; it is allowed between sums only (`canCash`: sum 0, or a finished sum / level-up card still on show). Getting **stuck** busts the streak (`bust()`): the pot is lost, then the usual stuck choices apply. A pot still open at game over is lost (the result says so, `res.potLost`). The `#streak` row (multiplier for the next sum, `STREAK_MAX` pips, Cash in + pot) sits in `.actions`: its own row in portrait (`order: -1`), under Shuffle in landscape; `.game.has-streak` shrinks `--cell` so it fits. A coach tip explains it until the first cash-in (`plus9.cashed`). New players are pointed at it: the home Classic card shows **¡Nuevo! Rachas ×5** until Classic is played (`plus9.classicSeen`), and the first win of journey level 5 adds a tip to the result. Sound follows the streak: each sum's arpeggio starts higher (`sfx.complete(tiles, mult − 1)`), cashing in plays `sfx.cash(mult)`, a bust `sfx.bust()`. If a lost pot would have beaten the record, the result says so (`res.potRecord`). The score and the pot count up when they grow (`showCount`). Classic also shows the `QUEUE_SIZE` (2) tiles after Next (`queue`, `#queue`), redrawn at level-up. `tools/balance.js` checks the decision matters: cashing at ×3–×5 beats cashing every sum and never cashing.
- **Levels** (Classic, 60 s, Daily): every `SUMS_PER_LEVEL` (4) sums, no top level. Target follows `TARGETS` (9 … 20), then +2 per level. The `#levelup` card shows the old target struck through and the new one.
- **Shuffle** rerolls all 8 tiles (key `S`). Free shuffles: 1 at the start, +1 per level-up while under 3. Otherwise it costs `SHUFFLE_COST × level × (paid so far + 1)` points.
- **Losing**: going over the target ends the game, except that once per game (not in the Daily, only with `platform.hasRewarded`) `offerRevive` first shows the result sheet as **¡Por poco!** with **End game** and **🎬 Take it back** (`#over-reward`): the ad runs after the sheet closes, and watching it takes the tile back (it never left the board, so only `sum` drops). **Stuck** (sum above 0, no tile fits) blocks play until the player acts: free shuffle, pay, **Bank** (key `B`: end and keep the points; in Spanish **Plantarse**, since **Cobrar** is the Classic cash-in; in the Journey it reads **Give up**) or **🎬 Free shuffle** when `platform.hasRewarded`. With none of those available the game ends.
- **Records**: the final score, per mode (`plus9.best.classic`, `plus9.best.timed`), so points spent on shuffles count against it. The result sheet compares the score with the previous record.
- **Journey** (`journeyLevel(n)`): a fixed seeded board; make the target `sums` times at a fixed difficulty (no level-ups). Special tiles are off until level 6 (`specials`). `setup` (applied by `applySetup` in both the game and the bot) hands out a wild tile on level 6, a ×2 on level 7 and a rainbow tile on level 8, and freezes two tiles on the 1st, 3rd and 5th level of every tier from level 11. Coach tips introduce each one (6, 7, 8, 11) with a highlighted tile. Tier = every 5 levels (target 9, 10, 12, 14 …); within a tier sums go 3 → 7. Stars: 1★ finishing, 2★ and 3★ at score thresholds from `journeyStars` (2★ ≈ a typical player, 3★ ≈ the careful bot). Level 1 starts from a hand-picked board. Levels 1–4 show coach tips (`tutorial()`): level 1 walks through the first sum with a highlighted tile; 2 = Next, 3 = color combos, 4 = shuffle. `JOURNEY_SEEDS` (levels 1–80) were chosen by `tools/journey.js` so typical players win ~95 % at level 1 down to 40 % (bosses a notch lower, down to 33 %); past 80 the seed is unchecked.
- **Daily** (`mode === 'daily'`): same tiles for everyone on a local date (`createRng(hashSeed(todayKey()))`). **All randomness goes through `rng`; never call `Math.random` directly for game draws.** `DAILY_SUMS` (12) sums, one attempt. Progress is saved on every `render()` (`plus9.daily`), so reloading resumes instead of rerolling. **Par** = what the careful bot scores on today's board (`todaysPar()`); shown when the daily starts, in the HUD and in the result and share text. Result: 2×6 emoji grid (🟦 2 tiles, 🟪 3, 🟨 4+, 💥 bust, ⬜ unplayed), streak (`plus9.streak`), countdown, Share (`navigator.share` or clipboard, URL from `platform.shareURL()`). Daily #1 is `DAILY_EPOCH`: **set it to the launch date before publishing**.
- **Missions** (`meta.MISSIONS`): 3 a day, the same for everyone (seeded by the date). Events from `app.js` (`meta.missionEvent`) advance them; each completed mission adds a star to `plus9.wallet` and shows a toast.
- **Stars**: total = journey stars + mission stars + bonus stars (`plus9.wallet.bonusStars`): a journey win with stars the level never had before offers **🎬 +N ★** on the result sheet (`doubleStars`), doubling only those new stars so replays can't farm them. Stars buy the star-priced wardrobe items.
- **Worlds** (`WORLDS`, `WORLD_SIZE` = 10 in rules.js): grape, sunset, ocean, night, candy, forest, space, neon; past level 80 the journey stays in neon. The map shows a banner where each world starts; each world's last level is a **boss** (`isBoss`: 8 sums, and from level 20 three frozen tiles; title "Boss: level n", crown on the map). Beating a boss for the first time completes the world (`completeWorld`): Nine gets and wears the world's item, the next world's theme switches on, and the result sheet shows the prize (`#over-prize`).
- **Themes** (`meta.THEMES`) are the worlds: a world's theme (background `--bg` and music style) unlocks when the player reaches it (`meta.worldReached`) and is chosen in the Customize sheet.
- **Nine's wardrobe** (`meta.WARDROBE`): one item per completed world (party hat, sunglasses, diving mask, wizard hat, bow tie, explorer hat, antennae, headphones) and three bought with total stars (cap 15, scarf 30, crown 60). One item per slot (head, face, neck), saved in `plus9.outfit`. Locked items show as grey previews with how to get them. `announceNewItems()` toasts items unlocked since the last check (`knownItems`).
- **Pause**: the help sheet is the pause menu (`Esc`, the pause button; `H`/`?` too). It pauses the 60-second clock, and so does hiding the page. `M` mutes.

## Saving

Everything is `localStorage` under `plus9.*` (each access in try/catch): `best.classic`, `best.timed`, `daily`, `streak`, `journey`, `missions`, `wallet`, `theme`, `outfit`, `muted`, `music`, `onboarded`, `cashed`, `classicSeen`, `lang`. No backend. On Poki, a logged-in player's `localStorage` is synced to their account automatically by the SDK (restored across devices, 1 MB limit); keys starting with `poki_ignore` are excluded. Keep saves small and in `localStorage` so that keeps working.

## Balance

`node tools/balance.js` (rules.js + bot.js): normal player's dead-end rate ≈16 % at level 1 rising ~2 points per level; whole games: normal ≈27 sums, careful ≈125, none endless (wild tiles soften bad luck). The streak table (`simulateRun({ bankAt })`): median Classic score by when the bot cashes in; normal ≈320 cashing every sum vs ≈450 at ×3–×5, careful ≈4500 vs ≈8900. Run it before and after touching `TARGETS`, `TILE_LAMBDA`, `SUMS_PER_LEVEL`, `MAX_FREE_SHUFFLES`, `SHUFFLE_COST`, `COMBO_MULTIPLIER` or `STREAK_MAX`. If the journey's rules change, rerun `node tools/journey.js` and update `JOURNEY_SEEDS`.

## Portals (Poki first, CrazyGames later)

`platform.js` hides each SDK behind `init`, `loadingFinished`, `gameplayStart`, `gameplayStop`, `commercialBreak()` → Promise, `rewardedBreak()` → Promise<boolean>, `shareURL()`, `hasRewarded`, `adShowing`. `window.PLUS9_PLATFORM` picks the SDK (`'poki'`); unset means `'none'`: no-ops and **no rewarded ads** (a self-hosted copy would otherwise hand out unlimited free shuffles). `?testads` simulates 1.2 s ads locally.

The adapter enforces Poki's rules (no repeated start/stop, no events during ads, ad promises always resolve). `app.js` calls `gameplayStart()` on the first input; `gameplayStop()` on game over, level-up, pause and leaving; `commercialBreak()` when starting a game, after the level-up card and when unpausing mid-game; `rewardedBreak()` only from 🎬 (free shuffle while stuck, take-back after going over, +N ★ on a journey win). During an ad: audio suspended, clock paused, `body.is-ad` blocks input.

Poki UI rules followed: 16:9 frames (640×360, 836×470, 1031×580) use the landscape layout; the 🎬 button is never green, sits beside or after the standard choices and is never larger or animated; no external links or requests; arrow keys, space and the wheel don't scroll the host page except inside `.sheet` and `.scroll` (the map).

**Build**: `node tools/build.js poki` adds `<script src="https://game-cdn.poki.com/scripts/v2/poki-sdk.js">` (no SRI: Poki updates that file in place) and zips the package. Verified over HTTP with the real SDK: it loads, and the event order is start → stop (level end) → commercialBreak (next start) → start → stop (pause) → commercialBreak (resume). **Still to do**: upload to Poki for Developers, run Poki Inspector, set `DAILY_EPOCH` to the launch date. The animated thumbnail, screenshots and listing texts are in `promo/`.

## Conventions

- **Input** goes through `play(tile)`: `click` for tap/keyboard, Pointer Events with a `.ghost` clone for drag; the click after a drag is suppressed. Drag writes the ghost's `translate3d` once per animation frame, eases its tilt from horizontal speed, and hit-tests a circular `dropZone()` measured at drag start (never the live well rect: the well scales up under a tile, and measuring that made it flicker at the edge). On release the ghost slides into the well or back home (`land`).
- **Ring**: one SVG segment per unit of the target, coloured by the tile that filled it.
- **Nine** sits in the actions row (top of the actions column in landscape) and is the "9" of the home title. Moods: hop on every tile, happy on a sum, cheer on combos / ×2 / level-ups / wins / new records (with confetti), worried while stuck, sad on a loss. Confetti also marks the tutorial's first sum. Confetti skips with reduced motion; the mascot's only idle motion is a blink every few seconds.
- **Poking Nine**: on the home screen (title) and in Customize, Nine is a `.nine-poke` button (`pokeNine`). Pokes cycle love (hearts), spin, wink (star), boing; five pokes within two seconds make it dizzy (spiral eyes, wobble). Each has a sound (`sfx.poke(kind)`) and floating symbols (`.poke-bit`, skipped with reduced motion). Its open pupils follow the pointer or last touch there (`mascot.look`), never during play.
- **Motion** only answers the player (pop-in, match, shake, bump, floating points, level-up card, result stars). The only loop is the Shuffle `nudge` while stuck and payable. Tutorial hints are a steady gold ring, not an animation. `prefers-reduced-motion` turns motion off.
- **Numbers** on tiles, Next and help icons are outlined with 16 unblurred `text-shadow`s (radius `--o`), not `-webkit-text-stroke`.
- **The target is always prominent**: an empty well shows it big in gold under "Make".
- **Labels** on pills and buttons use `--label-font`/`--label-size` (Ranchers 400), ink on white. Baloo 2 is for running text.
- **Icons** are `<symbol>`s in `index.html` used via `<use>`; CSS can't reach inside them, so state changes swap the symbol (`#i-sound-on` / `#i-sound-off`) instead of styling inner paths.
- **Layout**: `--cell` sizes the board. Portrait is one column (max 460 px); landscape-and-short switches the game to three columns (info | board | actions) and home to two. Check 375×667, ~1000×780, 640×360, 836×470 and 1031×580 after layout changes; none may scroll except the map route.
- **Ids**: the result sheet has both `#over-reward` (the 🎬 revive / double-stars button) and `#over-prize` (world prize); check `index.html` for an existing id before adding one.
- **Text**: never hard-code player-facing words in app.js or index.html; add a key to every language in `i18n.js` (keep the six dictionaries in step; a quick Node check compares their keys). Game-over reasons are passed as `{ k, v }` and translated when shown (`say`), so a saved daily result follows the current language. Check the longest languages (de, fr) at 375 px after UI changes. French uses no-break spaces before ! ? : ;.
- **Style**: 4-space indent, no semicolons, `const`/`let`, no implicit globals; `localStorage` always in try/catch; set user-facing text with `textContent`.

## Testing

No test suite. In a browser: first visit (clear storage) → tutorial level 1 → result → next level intro → map → home; each mode to the end; stuck → shuffle/pay/bank/🎬 with `?testads`; daily reload mid-sum; missions completing (toast, stars); themes unlocking; every layout size above. State is in top-level `let`s, so DevTools can force situations, e.g. `freeShuffles = 0; score = 5; setTile(tiles[0], { value: 7, color: '#ff31cc' }); checkStuck()`, or `meta.journeyRecord(5, 3)` to unlock levels.
